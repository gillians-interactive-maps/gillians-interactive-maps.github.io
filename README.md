# Gillian's Interactive Maps

Free and easy-to-use interactive maps for various videogames, focused on 100% completion for your favorite videogames

---

## Running Locally

These maps can be served locally using one of the following methods:

### Using Python 3:

```bash
python -m http.server 8080
```

### Using Node.js (`npx serve`):

```bash
npx serve -l 8080 .
```

Then open your browser to **[http://localhost:8080](http://localhost:8080)**.
